# 📚 Book Store Management System

A Java desktop application built with a Client-Server architecture for managing a bookstore. The project demonstrates object-oriented programming principles, layered architecture, socket communication, and JavaFX for the graphical user interface.

## Features

- User-friendly JavaFX interface
- Client-Server architecture
- Book management
- Customer management
- Socket-based communication
- Layered architecture
- DAO design pattern
- Maven project structure

## Technologies

- Java
- JavaFX
- Maven
- Socket Programming
- OOP
- DAO Pattern
- Git

## Project Structure

```
src/
├── books/
├── dao/
├── server/
└── ui/
```

## Getting Started

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the server.
4. Run the client.
5. Use the application through the JavaFX interface.

## Learning Objectives

This project was developed as part of a Computer Science course to practice:

- Client-Server programming
- Object-Oriented Programming (OOP)
- JavaFX development
- Socket communication
- Layered software architecture
- Design patterns (DAO)
